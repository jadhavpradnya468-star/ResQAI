# 🌍 The Problem

Every day, injured animals suffer on roads and streets because people:

❌ Don't know emergency first aid  
❌ Can't quickly find nearby veterinarians  
❌ Have no way to report rescue incidents  
❌ Cannot verify rescue authenticity to doctors  

## Result?

Thousands of animals remain untreated during the most critical moments.

---

# 💡 Our Solution — ResQAI

ResQAI is an AI-powered Progressive Web App designed to make emergency animal rescue fast, intelligent, and accessible.

Using AI + GPS + Real-Time Reporting, ResQAI helps users:

✅ Detect injured animals from uploaded photos  
✅ Analyze injury severity using AI  
✅ Get instant first aid guidance  
✅ Locate nearby veterinary hospitals  
✅ Send geotagged rescue reports directly to doctors via WhatsApp
